# جامعة صحار — الجولة الافتراضية ثلاثية الأبعاد

مشروع ويب ثلاثي الأبعاد (Three.js) لجولة افتراضية داخل حرم جامعة صحار، بملف **واحد** مكتفٍ ذاتياً
يحتوي كل النماذج والصور مدمجة داخله بصيغة base64.

## 🚀 التشغيل السريع

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
node src/_serve.js        # http://localhost:8899
```

ثم اكتب **آيدي الجامعة** و**اسمك**، واختر الشخصية (👨 ذكر / 👩 أنثى)، ثم اضغط **دخول**.
الزائر بلا كتابة يختار «دخول كزائر».

## 🌐 النشر على GitHub Pages

المستودع جاهز للنشر كما هو: الملف `index.html` موجود في **جذر** المستودع.

1. Settings → Pages → Source: **Deploy from a branch** → الفرع `main` → المجلد `/ (root)`.
2. الرابط Becomes: `https://<اسم-الحساب>.github.io/sohar-3d-tour/`

أو بأمر واحد:

```bash
gh api -X POST repos/<owner>/<repo>/pages -f source[branch]=main -f source[path]=/root
```

## 🗂 بنية المشروع

| المسار | الوصف |
|---|---|
| `index.html` | **المخرج النهائي**: صفحة واحدة مكتفية ذاتياً (كل الأصول مدمجة). هذا هو ما يُنشر. |
| `src/_v3_head.html` | قالب HTML (الهيكل + شاشة الدخول + CSS). |
| `src/_v3_app.js` | الرندر، الكاميرا، الإضاءة، الظلال، الأرض، المباني، النافذة المصغّرة. |
| `src/_char3.js` | الشخصيات: تلوين الخامات، الكمّة، تنورة الثوب، الحجاب، ربط الملابس بالعظام، ظل التماس. |
| `src/_online.js` | الطبقة الأونلاين: MQTT، الحضور، الأقران، الدردشة، فقاعة الشات. |
| `src/_bldgen.js` | توليد مباني الحرم من بيانات `su-campus.json`. |
| `src/_treelib.js` | الأشجار والنخيل وتوزيعها على الخريطة. |
| `src/build_final.py` | سكربت التجميع: يدمج كل الملفات + base64 → `index.html` واحد. |
| `src/_weldbuild.js` / `_weldtrees.js` / `_optbuild.js` | ضغط النماذج (weld + تكميم الخامات) وتقليل الصور. |
| `assets/` | الخامات والنماذج (نسخ مضغوطة) — الواجهة النهائية لا تحتاجها لأنها مدمجة. |
| `src/su-campus.json` | بيانات مباني الحرم (أسماء، إحداثيات، واجهات). |

### إعادة البناء

```bash
cd src
python build_final.py     # يخرج index.html + _v4.html + site/index.html
```

> الأصول الثقيلة الخام (`assets/trees`, `assets/topt`) مستثناة من المستودع بسبب حجمها؛
> النسخة النهائية `index.html` تحتوي كل شيء مدمجاً، لذا النشر لا يحتاجها إطلاقاً.

## 🛰️ الطبقة الأونلاين

- الوسيط: **MQTT over WebSocket** على `wss://broker.hivemq.com:8884/mqtt` مع احتياطي
  (`emqx`, `mosquitto`) وتدوير تلقائي عند فشل الاتصال.
- الموضوع: `su3d/sohar/v1/state`
- الرسائل: `hi` (تعريف الهوية) · `pos` (الموضع) · `say` (دردشة) · `bye` (مغادرة).
- نبض الحضور يعمل داخل **Web Worker** حتى لا تتجمّد التبويبات الخلفية.
- لا توجد بوتات ولا حسابات: كل قرين حقيقي يأتي من رسالة على الموضوع.
- **تنبيه**: الوسيط عام، Anybody يستطيع قراءة نفس الموضوع. للخصوصية الكاملة اربطه بـ broker خاص.

## 🎨 الشخصيات

مبنية على **Rocketbox** من Microsoft بترخيص MIT (`dl_rb_male.glb` + `dl_rb_female.glb` + `dl_rb_anims.glb`).
إعادة التلوين تتم عبر `COLOR_0` مع شيدر يحافظ على طيّات القماش، والملابس تُبنى على قياسات
الجمجمة الحقيقية وتُربط بالعظام لتتبع الحركة (`rbLocalize` + `rbBind`).

## ⚠️ ملاحظة

في متصفحات iPad/iOS قد يظهر خطأ `TypeError: undefined is not an object (evaluating 'o[0].x')`
عند التكبير بإصبعين — سببه غياب فحص لعدد نقاط اللمس في معالج `pointermove` داخل `src/_v3_app.js`.
